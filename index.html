משימה: חקירת Dataset וגילוי תובנות

המשימה: אתם צוות מדעני הנתונים! בחרו מאגר נתונים מתוך הקלאסרום, חקרו אותו וגלו: איזה סיפור הנתונים שלכם יכולים לספר?

הערה למשימה: היכנסו לגוגל קלאסרום ובחרו קובץ Dataset אחד בלבד מתוך המאגרים הממתינים לכם במשימה. פתחו את קובץ ה-CSV ועבדו איתו.

הנחיות לעבודה

1. בחירת Dataset ביחרו בקלאסרום קובץ נתונים בנושא שמעניין את הצוות שלכם ופתחו אותו.
2. איסוף וסיווג הבינו איזה DATA נאסף במאגר ואילו סוגי משתנים קיימים בטבלה.
3. מציאת דפוסים חפשו לפחות 3 דפוסים, קשרים או תופעות מעניינות בנתונים.
4. הפיכת תובנה לסיפור גבשו מסקנה מרכזית והמלצה מעשית מבוססת דאטה.
